重新学习强化学习，可以从以前参加开悟时接触过的王者荣耀任务出发：模型如何取得观测、选择动作、得到反馈，又如何判断这一轮训练是否真的变好？

我参加过两届开悟，队名“线性代数”，主要是王者荣耀方向。当前回忆年份约为2023、2024，具体奖项待核对。本篇整理新的学习和训练流程，不声称恢复当年的参赛模型或成绩。

## 先分清三种实验

第一种是机制热身：用自己可完全检查的小环境，确认采样、价值更新和终止处理。第二种是开悟赛道基线：使用对应开发包和正式评测协议。第三种是具身课题：把方法放进机器人自己的观测与动作定义中。

腾讯 [HoK官方文档](https://aiarena.tencent.com/hok/doc/) 有观测、动作、奖励和回放入口，并介绍 SAIL 训练框架。这些是理解研究系统的资料；具体年份/赛道的开发包与接口还需单独确认。本次没有使用开悟账号、运行受限环境或提交比赛模型。

## 一个真的会更新参数的热身

配套代码提供自建7×7网格 Q-learning，动作是上下左右，输入为当前位置和四邻域障碍，目标固定。三张地图用于训练，两张额外地图只做评测；它不是开悟的峡谷漫步，也不是包含视觉语言输入的 VLN。

在服务器进入下载包中的目录执行，无需额外 Python 依赖：

```bash
python scripts/grid_rl.py --episodes 4000 --seeds 7 19 43 --output runs/grid-rl-001
```

程序输出每个种子的 Q 表、逐 episode 训练记录、配置及按地图/起点列出的评测。Q表通过环境交互更新，学习率0.2，折扣因子0.97，探索概率逐步下降至0.05；这些只是本练习的固定设置，不是官方比赛参数。

本次对代码做了小规模自动检查，没有在服务器执行上述完整训练；成功率应以实际运行后的评测文件为准。

## 检查奖励是否对应目标

练习中到达目标奖励1.0，碰撞奖励-0.12，普通移动奖励-0.02。若只看累计回报，很难知道策略是不是靠减少移动、过早结束或反复撞墙取得表面改善，因此评测另外保存成功、碰撞、步数和截断。

Q-learning 更新可写成：

```text
目标 = 奖励 + 折扣因子 × 下一状态的最大Q值
新Q值 = 旧Q值 + 学习率 × (目标 - 旧Q值)
```

真正到达目标时，不再加入下一状态价值。人为步数限制的截断则需要区别处理：本练习将其视为对持续任务的采样截断，仍进行自举。如果把有限剩余时间定义为任务状态，建模和终止规则也应相应调整。[Gymnasium终止与截断说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

## 评测不能只用训练地图

训练只使用 train 开头的地图。评测采用固定起点，策略冻结不更新，比较 Q-learning、局部贪心和随机策略。读取全图的 BFS 最短长度仅供评测参考，不作为智能体输入，也不与局部观测策略混为同等信息权限。

Q表对新障碍布局失败很正常。先查看它是否依赖训练中见过的状态，再考虑历史记忆和函数逼近。训练回报变高不能替代独立地图上的任务完成情况。

## 回到王者荣耀，先跑固定官方基线

正式实验先记录年份、赛道、开发包与环境版本，确认观测、结构化动作、合法动作约束、对手和回放协议。四方向网格动作不能直接套到王者荣耀；这里也没有虚构一个适配器，声称能直接上传比赛。

离散导航可比较 Q-learning/DQN/PPO。王者荣耀方向使用什么算法与数据结构，要以相应开发包为准。[PPO原论文](https://arxiv.org/abs/1707.06347) 适合学习其采样与更新方式，但选择算法不能替代奖励、特征和评测设计。

每轮先固定网络、训练环境步数和对手集合，再分别改变奖励、观测或记忆。训练奖励、官方得分和评估胜率分别记录；注明对手版本、阵容与评估对局数。自博弈还需对手快照和独立对手池，避免只学会击败单一对手。

## 服务器实验要留下什么

每次使用新实验目录，记录代码/环境/配置版本、随机种子、实际采样步数、优化步数、训练时间和检查点选择规则。数据与测试协议在选参前确定，失败和中断也保留。

保存权重用于推理；若要断点续训，还要保存优化器、随机状态及必要的采样状态。当前基础停车训练仅保存最佳模型，未提供长任务无缝恢复。后续服务器训练器应把恢复能力单独实现和检查。

## 最后接到具身智能课题

把局部观测、长时奖励与记忆选择迁移到空间导航，把有限技能、动作后置条件和恢复策略接入 PickGo。游戏中的表现只能说明对应游戏条件下的能力，机器人还需要独立的传感、标定、动作和评测。

从简单 RL 热身，到开悟服务器基线，再到 [三项候选作品](#/post/embodied-kaiwu-training-roadmap)，可以共用实验记录思路。下载 [训练工程](https://williamtymhuabian.github.io/personal-site/downloads/embodied-training-lab.zip) 或阅读 [源码与任务卡](https://github.com/williamtymhuabian/personal-site/tree/main/examples/embodied-training)，完成后将真实收获关联到研究方向和个人学习榜。
