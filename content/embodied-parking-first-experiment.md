这次从一个已经存在的问题开始：PickGo 把取物停车位的 y 固定在0.32米。目标从 y=0.76米移远后，同一条动作流程可能在预抓取阶段出现超出机械臂工作空间的错误。

实验目标很小：为不同目标生成候选停车位，训练评分网络，再观察模型在新目标上能否帮助选择。数据生成、参数训练和仿真回放已经执行；没有提交服务器作业，也没有训练视觉模型或控制实体机器人。

## 数据来自哪里

直接调用现有 PickGo 的运动学核心，保持机器人结构和桌面布局不变。每个目标采样48个停车候选，用底盘间隙和若干阶段端点逆运动学产生标签，共192个目标、9,216条候选记录。

96个训练目标、32个验证目标、32个测试目标，另有32个较远目标用于分布外压力测试。每个目标及其候选只属于同一组，按目标所在空间单元划分，防止同一目标泄漏到训练和测试两边。

这仍是一个固定布局内的窄任务；相邻空间单元具有相关性，不是跨房屋或实体泛化实验。标签也不包含连续机械臂路径、完整碰撞或真实抓取动力学。

## 模型实际学习了什么

输入8个几何量：目标和底盘坐标、相对位置、平面距离与距离平方。网络为8→24→1，隐层使用 tanh，输出经 sigmoid 后得到候选评分，训练使用二元交叉熵与 Adam。

均值和标准差只从训练集计算。训练160轮，种子为7、19、43，按最小验证 BCE 保存权重；测试与分布外数据不用于选择检查点，分类阈值预先固定为0.5。

三个种子的初始训练损失约0.7568、0.6966、0.7672；最佳验证损失约0.00741、0.00618、0.00646。模型确实发生参数更新，并保存了权重和每轮损失。

这些输入是仿真几何量，不是相机观测。当前任务属于监督学习的几何可行性近似，不能写成 VLN、VLA 或强化学习成果。

## 为什么必须比较几何规则

完整回放比较五种方法：原固定停车位、距初始底盘最近候选、按距离依次几何验证、模型直接选最高分、模型排序后几何验证。后四者使用同一候选集合；固定位置保留旧程序规则，可能不在采样网格中。

32个测试目标的结果在三个种子下相同：

- 固定停车位：成功6，失败26。
- 最近候选：成功0，失败32。
- 按距离几何验证：成功9，拒绝23。
- 模型直接选：成功9，失败23。
- 模型排序后验证：成功9，拒绝23。

模型排序目前没有超过几何验证的成功数。排序后验证的平均端点检查次数约34.78，按距离验证约41.22；这只是检查次数，未计入网络推理和排序开销，不能当成总耗时加速。

## 高准确率掩盖了什么

测试候选1,536条，只有39条为正例。因此即使始终预测不可行，普通准确率也约97.46%。本次同时保存混淆矩阵和平衡准确率，避免只展示一个接近100%的数字。

更关键的是，在32个测试目标中，仅9个存在通过端点检查的采样候选。模型无法解决其余目标时，需要区分模型排序错误与候选不足，不能统一归结为“训练还不够久”。

较远目标的1,536个候选全部不通过端点检查。两种带验证的方法全部拒绝，其余方法全部失败；此时分类准确率100%也没有完成任何任务。它不足以证明模型分布外泛化，更不说明真实机器人或其他停车搜索必然无解。

## 下一轮先改变实验，而非只换大模型

先在训练与验证集分析底盘间隙、预抓取高度和关节限制，再设计更密或侧向候选。由于已经查看过这批测试结果，下一轮选参应建立新的封存测试集，保留当前结果作为历史记录。

如果低成本几何检查已经足够，就继续使用它。更值得研究的可能是观测变化、目标定位误差、失败后的重新观察与重新停车；是否需要学习方法，要由对照结果决定。

## 在服务器重跑

下载 [基础训练包](https://williamtymhuabian.github.io/personal-site/downloads/embodied-training-lab.zip)，解压进入工程目录。Python建议3.11，Node.js需18或以上，基础训练只依赖 NumPy：

```bash
python -m pip install -r requirements.txt
python scripts/run_server.py --output runs/server-parking-001
```

输出目录必须是新的，程序不会覆盖历史实验。包内已有运动学核心副本，保留来源和哈希；改变核心后要重新生成数据和训练，回放会检查版本是否一致。

历史权重、损失、候选排序请求与320条/种子的回放在 `sample-results/parking-v1`；模型三个种子复用同一批场景，不能把它们当成96个独立测试目标。每条回放可按 scene_id 查状态和失败阶段。[配套源码](https://github.com/williamtymhuabian/personal-site/tree/main/examples/embodied-training)
