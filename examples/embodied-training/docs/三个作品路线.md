# 三个候选作品：先共用底座，再形成独立能力

更新：2026-10-23。研究背景暂按具身智能 / VLN；训练地点按服务器安排。这里给出研发路线，当前已实现 README 中的停车候选训练实验和网格 Q-learning 热身，不把三个设想写成完成品。

强化学习部分结合本人“线性代数”队的王者荣耀方向开悟参赛经历，具体安排见《腾讯开悟实践指南》。

建议先完成作品一的基础版，再主攻作品二；作品三在 RGB-D 配准和标定具备后推进。前两项可先形成连续研究成果，第三项作为扩展。三个作品共用任务与证据格式，但功能、用户和验证目标不同；如果最终只形成一个紧密集成的软件，就按一个完整系统整理成果。

## 作品一：具身任务训练与故障回放平台

面向刚进入课题的学生，解决“例程跑通了，但不知道数据怎么来、模型学了什么、为何失败”的问题。输入任务配置、轨迹和模型版本，输出数据分组、训练记录、对照评测、失败阶段和可复查的回放。

最小完整功能：任务包导入与校验、只读仿真适配、轨迹 JSONL、训练与评测入口、模型/数据摘要、固定场景回放、结果导出。第一版可用命令行，之后再加前端，避免界面先于实验能力。

训练内容从小型停车评分网络开始，再加入失败类别分类和恢复动作选择。只有任务、示范与奖励已明确后，才比较行为克隆、数据聚合和强化学习；每项训练都必须有不学习的基线。

当前代码提供其中的数据生成、小网络训练、五种方法回放和版本记录。尚缺通用任务包、时间序列采集、故障注入、其他模型适配及完整软件操作文档。

预期成果：可运行软件、原创代码、数据格式说明、操作手册和实验报告，可作为软件著作权登记材料的研发基础。普通实验管理和回放本身不作为专利创新点。

## 作品二：面向动态场景的空间记忆导航 Agent

面向重复室内任务：先去桌边找杯子，过一会再去取，而杯子位置、通路或场景布置已经变化。核心问题是：怎样利用历史观测，又能识别不能继续沿用的旧证据？

最小完整功能：目标/房间/物体关联、观测来源与时刻、记忆检索、当前观测核对、规划与失败恢复、场景边界隔离。先做 ObjectNav 或简化目标导航；只有输入包含语言指令且具备视觉观测时才称为 VLN。结构化坐标任务不能直接宣称是 VLN 结果。

训练路线：先比较无记忆、固定窗口、向量检索、图检索；再训练检索重排器或“继续使用/重新观察/请求帮助”的策略头。服务器上固定同一个视觉编码器和导航器，先验证记忆方法贡献；有充足示范后再尝试小模型 SFT/LoRA，避免模型更换掩盖方法差异。

候选研究假设：把观测版本、变化证据与复查代价一起用于下一次观测选择，可能减少旧目标误用与重复探索。这个方向与既有空间记忆、图检索和执行保护高度相关，必须进一步收窄机制并验证差异。

评测：训练与测试按房屋/场景隔离；跨 episode 记忆限定在允许的场景，不能包含未来轨迹或测试标注。报告 SR、SPL、旧记忆误用率、重新观察次数、额外路程和失败恢复率。公平控制同一编码器、同一动作预算与输入权限。SPL 定义和成功半径采用所用基准原协议。

必要消融：去掉变化检测、去掉时刻/版本、随机复查、固定间隔复查、无记忆和只加记忆。至少三个训练种子，报告每场景结果；提升若只是花了更多观察预算，不能归因于记忆创新。

作品形态：可检索、解释和回放的导航软件；若窄机制确实解决技术问题，并经充分现有技术比较，可再整理发明交底。已有 [ConceptGraphs](https://concept-graphs.github.io/)、[WMNav](https://arxiv.org/abs/2503.02247) 和 [VTM-Nav](https://arxiv.org/abs/2607.14514) 可作为相关基础，不能把“记忆＋导航”当作我们的独创。

## 作品三：观测驱动的移动抓取校验与恢复系统

面向已有 PickGo 流程，解决“能到达某个抓取点，却在接近、抬升或托盘转换时失败”的问题。把停车选择、观测有效性和分阶段恢复连起来。

最小完整功能：RGB-D 帧与时间戳、标定和坐标系记录、候选停车位、阶段前置/后置条件、抓取结果确认、有限恢复动作和失败证据导出。当前只有 RGB 采集验证，不能跳过深度配准、标定和视觉闭环就宣称真实移动抓取成功。

训练路线：先做停车候选评分；随后加入含噪声的观测及遮挡，训练重观察/重新停车/保持等待等动作选择。用人工或验证器标注后果，保留负样例。真实数据从只读采集和回放开始，真实执行另行做台架验证。

候选研究假设：按动作阶段重新计算观测的适用范围，并结合底盘/机械臂状态决定复查与恢复，可能降低旧观测导致的错误执行，同时控制不必要的复拍。须比较固定超时阈值、每步复拍和已有置信度控制方法，不能把增加时间戳本身算作创新。

评测：目标位移、深度缺失、帧延迟、标定扰动、停车偏差分别分组；报告仿真任务成功、错误继续、正确拒绝、恢复次数和额外时间。实体实验另列定位误差、抓取成功和重复试验条件，绝不混入仿真统计。去掉阶段判别、时效条件和重新停车各做一次消融。

作品形态：可运行视觉闭环软件和实验数据；成果成熟后可讨论软件登记与具体控制方法发明。相关置信度抓取技术已见 [CN107220601B](https://patents.google.com/patent/CN107220601B/zh)，须逐项比较技术特征。

## 按里程碑推进

阶段一：读 Agent 第1、4、6章与 LLM 附录A，完成固定任务、数据校验、原固定停车位失败复现和第一轮训练。交付可重跑命令、权重、原始结果、本人写的解释。

阶段二：读 Agent 第2、3章与 GraphRAG 第2、3、6、8章，建立最小空间记忆数据集和四类检索基线。交付按场景分组的数据、检索错误清单与评测程序。

阶段三：读 Agent 第7、8章与 LLM 第5、6、7章/附录E，开展重排器或策略训练，再按失败类型补数据。交付不碰测试集的选参过程、三种子对照、消融和不改进的结果。

阶段四：读 Agent 第9、10章与 GraphRAG 第5章，连接观测与执行；需要时增加多模块协作，但先保持单 Agent 基线。交付完整作品一、作品二初版；作品三根据深度、标定和设备条件决定是否启动。

每阶段可安排1—2周作为学习节奏参考，按每周实际投入调整；这不是训练时长、论文产出或授权周期承诺。优先完成能解释的两项成果，再决定是否扩展第三项。
