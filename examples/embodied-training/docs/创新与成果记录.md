# 创新假设、检索与成果材料

检索日期：2026-10-23。本记录是研发用初步检索，不是查新报告、侵权分析或授权意见；当前没有已获证软著、专利或经过验证的原创方法。创新假设均需实验和更完整的权利要求比较。

## 已确认的相邻公开工作

[ConceptGraphs，ICRA 2024](https://concept-graphs.github.io/)：RGB-D 构建开放词汇三维场景图并支持规划。因此“把物体组成场景图再调用语言模型”不能直接视为新点。

[WMNav，2025](https://arxiv.org/abs/2503.02247)：将视觉语言模型、世界模型和导航反馈组合。需要比较我们额外引入的变化证据、复查策略到底解决了哪类失败。

[VTM-Nav，2026-07，arXiv 预印本](https://arxiv.org/abs/2607.14514)：研究跨 episode 的视觉拓扑记忆复用，并包含执行保护。与作品二非常接近；不能将“跨任务记忆＋当前观测核对”直接写成独有贡献。

[KnowNo / Robots That Ask For Help，2023](https://arxiv.org/abs/2307.01928)：研究规划不确定性与求助。因此“低置信度时求助”已有相关方法；我们若要研究，需要提出不同的技术机制和任务证据。

[CN121252786B：基于脑启发结构化空间记忆的具身导航方法、装置和设备](https://patents.google.com/patent/CN121252786B/zh)：涉及层次空间记忆、候选坐标、置信度和距离导向的探索。应重点比较记忆结构、检索路径、候选排序和控制流程。页面列示 B 文本公布日期2026-06-19；法律状态需另查官方登记。

[US20260064122A1：Artificial intelligence-based system and method for object detection and navigation](https://patents.google.com/patent/US20260064122A1/en)：涉及动态场景图、关系语义知识和目标导航，公开日2026-03-05。这是公开申请文件，不等于已授权专利；外国公开文献也需要纳入技术比较。

[CN107220601B：一种基于在线置信度判别的目标抓捕点预测方法](https://patents.google.com/patent/CN107220601B/zh)：涉及抓捕点预测、在线置信度和运动修正。不能把“置信度抓取”当作空白领域。进一步检索应覆盖主动感知、视觉伺服、事件触发控制和移动操作停车规划。

另检索到 [Mem4Nav](https://arxiv.org/abs/2506.19433)，其原始 arXiv 页面标明已撤稿；本工程不将其作为有效方法基线。检索结果摘要可能过时，采用文献前应检查原页面和版本。

## 需要验证的两项假设

H1：动态目标变化后，结合变化证据、历史观测适用范围与复查代价的观测选择，比固定窗口/固定复查更少误用旧目标，并保持相近动作预算。

比较对象：无记忆、向量记忆、图记忆、固定时间衰减、随机复查和最接近的跨 episode 方法。记录确切差异，而不是只写“增加了一个模块”。若提升仅来自更多调用、更强编码器或额外真值，假设不成立。

H2：把观测适用条件与抓取阶段、停车状态联合校验，比统一超时/统一重试更少错误执行，且额外观察成本可控。

比较对象：每次执行都重新拍照、固定 TTL、原固定停车位、纯几何停车和固定恢复表。当前 MLP 停车实验只是搭建训练和评测能力，不是 H2 的创新证据。若便宜的几何规则已经解决问题，应保留规则，不为使用神经网络而增加复杂度。

两项仍是宽泛研究假设，尚未形成可主张的区别技术特征。实验确定窄机制后，再检索中英文名称、近义词、相关分类、专利家族与引证，并按独立权利要求逐项比对。

## 成果准备的实际顺序

先完成能运行的软件和本人可解释的实验记录。软件著作权登记需结合申请表、程序/文档鉴别材料与证明文件准备；当前适合作为作品一研发起点，还不是登记就绪材料。[国家版权局登记办法](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)

发明应有具体技术问题、可实施的方法和可复查效果，满足新颖性、创造性和实用性；“用了 Agent/GraphRAG/LoRA”不足以证明。AI 训练/应用方案的说明书还需说明必要结构、训练步骤参数或输入输出与场景的关联。[专利法第二十二、二十六条](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_ff4a80ad7d7b46bc908ea03e96f272c3.html)、[国家知识产权局2025年指南修改解读](https://www.cnipa.gov.cn/art/2025/12/4/art_66_202935.html)

每个版本保留：设计者的具体改进、原始数据来源、标注准则、配置/代码/模型摘要、失败结果和修改理由。不要伪造作者贡献、训练结果或实验时间。复用库、旧项目和原书代码的来源与许可分别记录。

若涉及学校课题、导师任务或实验室条件，先向导师/学校成果部门确认申请人、发明人/作者贡献与归属；不预设为个人独有成果。对应依据见专利法第六条。

本次按维护者要求公开学习路线、基础代码、初步检索和宽泛研究假设；没有把这些内容认定为尚未公开的发明。后续如果形成具体候选核心方案，应单独确定公开安排。一般公开博客/Git 可能影响后续新颖性安排，不能默认享有六个月宽限期；专利法第二十四条列的是特定情形。先完成具体材料，再由维护者结合导师/成果部门决定申报及公开顺序。[专利法第二十二至二十四条](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_ff4a80ad7d7b46bc908ea03e96f272c3.html)
