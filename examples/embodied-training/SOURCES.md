# 来源与边界

阅读材料来自用户本地提供的三本 PDF。仅用于核对目录和设计原创任务；未复制原书正文、代码或 PDF 到本工程。

- 李博杰《深入理解 AI Agent：设计原理与工程实践》，v1.3，2026-07-30；[作者仓库](https://github.com/bojieli/ai-agent-book)。
- Tomaž Bratanič、Oskar Hane，Essential GraphRAG，Manning，2025；已核对本地 PDF 第7—10页目录。
- Sebastian Raschka，Build a Large Language Model (From Scratch)，Manning，2024；已核对本地 PDF 第7—12页目录。

实验标签与回放由维护者现有 [PickGo Lab](https://github.com/williamtymhuabian/pickgo-lab) 的 `simulator-core.js` 生成。训练器、数据适配器、任务卡为本次新编写内容；不依赖旧相机识别模块。

公开论文、专利和官方材料链接及它们对应的研发限制见 [创新与成果记录](docs/创新与成果记录.md)，检索时间2026-10-23。没有将搜索摘要中的指标当作本工程结果。

服务器扩展参考：[Habitat-Lab 原仓库](https://github.com/facebookresearch/habitat-lab)、[任务数据集清单](https://github.com/facebookresearch/habitat-lab/blob/main/DATASETS.md)、[PEFT LoRA 官方文档](https://huggingface.co/docs/peft/developer_guides/lora)。这些是后续可选基础设施，本次尚未安装、运行或完成复现；场景资产与任务 episode 的获取和使用条件需分别核对。
