# 从三本书走向具身智能课题

这是一套正在起步的研究训练工程，主线是：**把书里的 Agent、记忆检索和模型训练，变成能记录、训练、比较和复盘的机器人任务实验。**

当前已实现停车监督训练和自建网格 Q-learning 热身。停车实验：复用 PickGo 的实际运动学核心生成停车候选数据，训练一个 8→24→1 的 MLP，对未参与训练的目标位置进行停车位排序，再运行完整搬运仿真回放。代码确实更新参数并保存权重；输入只有几何量，不含图像或自然语言，因此不是 VLN/VLA 训练。

后续训练按服务器工作流准备。这里不根据个人电脑显存限定后续模型规模，不自动下载模型、安装 GPU 环境或提交远程任务。代码不启动浏览器、相机、MCP 服务或实体机器人。

## 从这里开始

5. 涉及创新方案时查阅 [创新与成果记录](docs/创新与成果记录.md)。其中都是待验证的研究假设，不代表已发现可授权发明。

## 服务器运行

建议先用 Python 3.11、Node.js 18+。当前基础实验只依赖 NumPy，不要求 CUDA。服务器尚未实际运行；本地执行的是小规模代码自检和基础实验。

将本目录完整传到服务器，已包含 `vendor/pickgo-core.js`；核心来自 PickGo，保留原样和来源说明。当前 SHA256：

`29595a1803c2cfbb402c8a8af0f74651c869d5fcdc1fa7a651b734f5b8072a90`

在本目录执行，运行基础训练：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/run_server.py --output runs/server-parking-001
```

Windows 激活环境可用 `.venv\Scripts\Activate.ps1`。已有适用 Python 环境时直接执行最后一条即可；不必重建环境。

`--output` 必须是新目录，避免覆盖上次实验。自定义训练轮数和种子时复制 `configs/parking-baseline.json`，用 `--config` 指定。`PICKGO_CORE` 支持独立调用数据/训练脚本时指定核心路径；一键入口会自动设置。

每次运行输出：

- `config.json`：本次配置；`dataset.json`：分组与全部候选数据。
- `training/manifest.json`：数据、核心与训练脚本摘要，环境、配置和候选覆盖情况。
- `training/seed-*/model.json`：模型权重、特征顺序和仅在训练集计算的标准化参数。
- `history.json`：每轮训练/验证损失；`metrics.json`：分类与任务结果。
- `requests.json` / `replay.json`：模型提出的候选次序和仿真实际结果，可回查失败阶段。
- `training/report.json`：最终汇总。多种子复用了同一批场景，不能把它们当作更多独立场景。

另一个独立的强化学习热身可执行 `python scripts/grid_rl.py --episodes 4000 --seeds 7 19 43 --output runs/grid-rl-001`，不需要 NumPy、官方开发包或账号。它没有开悟接口；训练与评测结果须由运行后确认。

训练进程失败时保留已写记录，换新输出目录重跑。本版保存最佳验证集权重，尚无优化器恢复和长任务断点续训。

## 实验比较什么

训练/验证/测试分别有 96/32/32 个目标空间单元；额外 32 个较远目标用于分布外压力测试。每个目标的 48 个候选全部放在同一组，避免同一目标的候选同时出现在训练和测试中。总计 9,216 条候选记录。

模型只读目标和停车位几何特征；标签来自底盘间隙检查和若干阶段端点逆运动学。它们不代表连续机械臂路径、完整碰撞检查或真实抓取可行性。

对照包括原固定停车位、最近候选、逐一几何验证、模型直接选择，以及模型排序后逐一几何验证。后四者使用同一候选集合；固定停车位是历史程序的单独基线，可能不在采样候选内。几何验证方法也是强基线，不能只和固定位置比较。

模型检查点仅按验证损失选取，0.5 分类阈值预先固定；测试和分布外数据不参与选参。完整仿真按固定 0.04 秒步长，从全新状态回放。

## 与现有项目的关系

本工程包含 PickGo `simulator-core.js` 的原样副本 `vendor/pickgo-core.js`；没有修改其原始视觉函数，也不包含相机采集、厂家 SDK 或旧机器人控制模块。实验通过独立仿真实例替换取物停车目标，不会改变线上演示。

本目录按维护者要求作为博客配套源码公开。三本原书 PDF、目录摘录、原始证书和开悟受限开发包不随工程分发。历史停车实验原始指标/权重/回放保存在 `sample-results/parking-v1`，重跑数据可由固定种子生成。书籍关系记录在 `curriculum.json`，使用现有网站的稳定书籍 ID、章节编号和研究方向 ID，后续可作为学习记录的关联数据；尚未接入网站打卡计分。

本工程由维护者确定课题与实验设计，AI 协助编写初始代码和材料；后续需通过本人理解、修改和独立复现实验形成研究贡献。当前目录没有对既有 PickGo 或原书材料重新声明许可证。
